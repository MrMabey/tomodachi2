## Upgrading from Old Setup

If you were using `start_tomo_gui.sh` before, here's what changed and how to migrate.

## Quick Migration

```bash
# 1. Pull latest changes
git pull

# 2. Create .env from template (optional, has good defaults)
cp .env.example .env

# 3. Use new startup script
./start.sh
```

That's it! Your existing venvs and data will be reused.

## What's Different?

### Startup Command

**Before:**
```bash
./start_tomo_gui.sh
```

**After:**
```bash
./start.sh  # Recommended
# or
./start_tomo_gui.sh  # Still works!
```

### Port Configuration

**Before:**
- Hard-coded in scripts and code
- Had to edit multiple files to change

**After:**
- Set in `.env` file
- Auto-finds alternatives if ports busy
- One place to configure everything

### Adapters

**Before:**
- Required, would fail if missing
- Hard-coded paths

**After:**
- Optional, graceful fallback to base model
- Configurable paths via `.env`
- Clear messaging about what's being used

## Configuration Changes

### Custom Ports

**Before:**
```bash
# Had to edit start_tomo_gui.sh line 42:
FLASK_RUN_PORT=5003  # Change this
```

**After:**
```bash
# Create/edit .env:
TOMO_MEMORY_PORT=5003
TOMO_API_PORT=8080
TOMO_GUI_PORT=5173
```

### Disabling Adapters

**Before:**
- Not possible, would crash

**After:**
```bash
# In .env:
TOMO_USE_ADAPTERS=false
```

### Debug Mode

**Before:**
```bash
# Edit code in tomo_api.py
```

**After:**
```bash
# In .env:
TOMO_DEBUG=true
```

## Common Issues After Migration

### "Port in use" errors

**Old behavior:** Failed silently or showed cryptic error

**New behavior:**
1. Tries default port
2. If busy, finds alternative automatically
3. Tells you what port it's using

**Manual override:**
```bash
# In .env
TOMO_MEMORY_PORT=5010  # Custom port
```

### Missing adapters

**Old behavior:** Crash with confusing error

**New behavior:**
```
⚠️  Adapters disabled (using base model only)
   Reason: Adapter weights not found
```

System continues with base TinyLlama. Works fine, just without custom fine-tuning.

### Different URLs

**Before:**
- GUI: http://localhost:8080
- Memory: http://localhost:5003

**After:**
- GUI: http://localhost:5173 (Vite default)
- API: http://localhost:8080
- Memory: http://localhost:5003

**Why?** The GUI is now properly served by Vite dev server (faster hot reload).

## Rollback (If Needed)

If something goes wrong, you can always use the old script:

```bash
./start_tomo_gui.sh  # Still works exactly as before
```

Or manually start services:

```bash
# Terminal 1
cd memories
source .venv/bin/activate
FLASK_APP=edge_rag.web:create_app FLASK_RUN_PORT=5003 python3 -m flask run

# Terminal 2
source venv/bin/activate
python3 server/tomo_api.py

# Terminal 3
cd campground
npm run dev
```
