# 🎭 Mood System - Quick Reference

## What It Does

The Mood System gives Tomo **9 distinct personalities** by automatically adjusting:
1. ⚙️ **Inference Parameters** (temperature, sampling, token length)
2. 📝 **System Prompt** (behavioral instructions)

Same question → Different moods → Dramatically different answers!

## The 9 Moods

| Mood | Emoji | Temp | Best For |
|------|-------|------|----------|
| **FOCUSED** | (o_o) | 0.3 | Code, precision, debugging |
| **CREATIVE** | (^-^) | 1.2 | Brainstorming, ideation, design |
| **HELPFUL** | (^_~) | 0.7 | Teaching, explanations, support |
| **LISTENING** | (•_•) | 0.5 | Gathering input, clarifying |
| **THINKING** | (◉_◉) | 0.6 | Analysis, reasoning, trade-offs |
| **SUCCESS** | (^o^) | 0.8 | Celebrating, encouraging |
| **ERROR** | (x_x) | 0.4 | Debugging, problem-solving |
| **SLEEPING** | (-_-) | 0.2 | Minimal responses, low-power |
| **PHONE_HOME** | (⊙_⊙) | 0.9 | Complex tasks, escalation |

## Quick Start

### In the GUI
1. Click any mood button
2. Parameters auto-adjust
3. Next message uses that personality!
4. Toggle "Mood Controls Parameters" to enable/disable

### Via CLI
```python
# In your code
state.current_mood = "CREATIVE"
# Next response will be creative and playful!
```

### Via API
```bash
curl -X POST http://localhost:5000/api/mood \
  -H "Content-Type: application/json" \
  -d '{"mood": "CREATIVE"}'
```

## Temperature Cheat Sheet

```
0.2 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ 1.5
 │                                  │
SLEEPING  FOCUSED  HELPFUL  CREATIVE
PRECISE   RELIABLE  NATURAL  WILD
```

- **Low (0.2-0.4)**: Deterministic, focused, repetitive
- **Mid (0.5-0.8)**: Balanced, natural, conversational
- **High (0.9-1.5)**: Creative, diverse, unpredictable

## When to Use Which Mood

### 📋 Task-Based Selection

| Task | Recommended Mood | Why |
|------|------------------|-----|
| Code review | FOCUSED | Precise, spot errors |
| Brainstorming | CREATIVE | Generate novel ideas |
| Learning | HELPFUL | Patient explanations |
| Requirements gathering | LISTENING | Brief, clarifying questions |
| Architecture design | THINKING | Methodical analysis |
| Tests passing | SUCCESS | Celebrate wins! |
| Bug fixing | ERROR | Solution-focused |
| Idle/standby | SLEEPING | Conserve resources |
| Beyond capabilities | PHONE_HOME | Escalate to external LLM |

## Creating Custom Moods

Edit `tomo_api.py`:

```python
MOOD_CONFIGS = {
    "YOUR_MOOD": {
        "params": {
            "temperature": 0.8,
            "top_k": 60,
            "top_p": 0.95,
            "max_new_tokens": 150
        },
        "system_prompt": "You are in YOUR_MOOD mode. [instructions]",
        "description": "What this mood does"
    }
}
```

## Troubleshooting

**Mood not changing behavior?**
- Check "Mood Controls Parameters" is enabled
- Verify sliders updated
- Look for mood in message metadata

**Responses too random/boring?**
- Too random → Lower temp moods (FOCUSED, ERROR)
- Too boring → Higher temp moods (CREATIVE, SUCCESS)

**Want manual control?**
- Uncheck "Mood Controls Parameters"
- Adjust sliders directly
- Parameters persist until next mood change
