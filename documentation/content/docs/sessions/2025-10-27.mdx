### 2. Message Positioning Fix ✅

**Problem:**
- Messages not appearing at midpoint
- Only loading dots visible
- Prior messages disappearing when new message arrived

**Solution:**
- Rewrote `positionMessages()` to calculate from bottom-up
- Used `requestAnimationFrame` for smooth positioning
- Calculate actual element heights with `getBoundingClientRect()`
- Position newest at center, stack older upward with 15px gaps
- Fade messages in top 100px zone

**Algorithm:**
```javascript
let currentY = middleY;
for (let i = messages.length - 1; i >= 0; i--) {
    const msgHeight = msg.element.getBoundingClientRect().height;
    if (i === messages.length - 1) {
        currentY = middleY - msgHeight / 2;  // Center newest
    } else {
        currentY = currentY - msgHeight - 15; // Stack upward
    }
    msg.element.style.top = `${currentY}px`;
}
```

### 3. Memory System Debug & Fix ✅

**Problem:**
- Raw memory metadata appearing in chat responses
- Full dictionary structure visible: `{'document': {'annoy_id': 41, ...}}`
- Context leakage from RAG retrieval

**Root Cause:**
- Memory service returning nested `{document: {text: "..."}}` structure
- Code accessing `mem['text']` but should be `mem['document']['text']`
- Model echoing the context prefix in responses

**Solution:**
1. **Better text extraction:**
```python
mem_text = (mem.get('text') or
           mem.get('content') or
           mem.get('document', {}).get('text'))
```

2. **Response filtering:**
```python
if "{'document':" in response:
    # Strip leaked context
```

3. **Disabled by default:**
```python
def process_chat_response(user_input, thread_id="default", use_memory=False):
```

## 📊 Memory System Details

**Vector Database:**
- Engine: Annoy (Approximate Nearest Neighbors)
- Dimensions: 384 (sentence-transformers/all-MiniLM-L6-v2)
- Storage: SQLite + Annoy index
- Location: `memories/data/`

**Metadata Tracked:**
- `doc_id` - Unique document identifier
- `annoy_id` - Vector index position
- `text` - Actual conversation text
- `thread_id` - Conversation grouping
- `embedding_time_ms` - Vectorization duration
- `retrieval_time_ms` - Query duration
- `similarity` - Cosine similarity score (0-1)
- `created_at` - Timestamp

## 💡 Key Learnings

1. **Absolute positioning for chat** - Better control than flexbox for this use case
2. **requestAnimationFrame** - Essential for smooth DOM updates
3. **Glassmorphism** - Backdrop-filter is expensive, use sparingly
4. **RAG context injection** - Small models easily leak context, needs careful prompt engineering
5. **Textarea auto-grow** - Set height to 'auto' first, then set to scrollHeight
