## TL;DR

```bash
./start.sh
```

Open http://localhost:5173 🏕️

## Common Commands

### Start Everything
```bash
./start.sh
```

### Check Setup
```bash
python3 validate.py
```

### View Config
```bash
python3 config.py
```

### Stop Everything
Press `Ctrl+C` in the terminal running `start.sh`

### View Logs
```bash
tail -f logs/memory.log
tail -f logs/api.log
tail -f logs/gui.log
```

## Port Conflicts?

Edit `.env`:
```bash
TOMO_MEMORY_PORT=5010
TOMO_API_PORT=8090
TOMO_GUI_PORT=5180
```

## Missing Adapters?

**It's fine!** System uses base TinyLlama model. Everything still works.

## Need Help?

1. `python3 validate.py` - What's wrong?
2. [Setup Guide](/docs/getting-started/installation) - Detailed guide
3. `logs/` - Error details

## Architecture

```
Campground (5173)
    ↓
API Server (8080)
    ↓
TinyLlama + Memory (5003)
```

## Development

### Frontend
```bash
cd campground
npm run dev
```

### API
```bash
source venv/bin/activate
python3 server/tomo_api.py
```

### Memory
```bash
cd memories
source .venv/bin/activate
FLASK_APP=edge_rag.web:create_app python3 -m flask run
```
