# 🤖 Mental Models

Adapter training, fine-tuning, and model optimization

## Backlog

### Q&A: Should opinion questions route to chat or command?

Testing shows orchestrator incorrectly routes opinion questions to COMMAND mode.

**Example:**
- **User:** "What's your favorite color?"
- **Current:** `Mode=COMMAND`, `Intent=get_favorite_color`
- **Expected:** `Mode=CHAT` (conversational response with personality)

**Issue:** Questions asking for Tomo's opinion/preferences should route to chat, not command execution.
